# Brain Tumor MRI Classification

This project uses the [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) from Kaggle.

## Dataset

The dataset is **not included in this repository**.

Download it from Kaggle and place the `Training` and `Testing` folders inside the `data/` directory.

The structure should be:

```text
data/
├── Training/
│   ├── glioma/
│   ├── meningioma/
│   ├── pituitary/
│   └── notumor/
│
└── Testing/
    ├── glioma/
    ├── meningioma/
    ├── pituitary/
    └── notumor/
```

Once the dataset is in the `data/` folder, the project is ready to run.
